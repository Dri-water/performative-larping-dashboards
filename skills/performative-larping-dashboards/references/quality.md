# Acceptance: magnificent nonsense, solid execution

Score each dimension 0 (absent), 1 (generic), 2 (convincing), 3 (exceptional):

| Dimension | What earns the score |
|---|---|
| Identity | Subject-specific physical world, recognizable without labels |
| Hero | Sculptural centrepiece, materials, occlusion, distinctive silhouette |
| Cast | Agents differ by form, role, movement, and voice |
| Causality | A visible event propagates through scene, instruments, and receipt |
| Density | Multiple scales of authored detail with a readable hierarchy |
| Motion | Layered rhythms, purposeful transitions, deliberate still composition |
| Social | Desktop and portrait both authored; first frame sells the artifact |

Target at least 16/21 with no zero. This is an editorial rubric, not an automated
quality claim. Do not mark it passed without looking at rendered output.

Hard delivery checks:

- Controls work; pause freezes all ongoing motion; resume does not jump.
- Simulated data is labeled; real failures cannot appear as fictional success.
- Hero survives missing assets or unavailable GPU through a visible fallback.
- Text, keyboard focus, and core controls remain legible at target sizes.
- Reduced motion and hidden-tab behavior work. No fullscreen strobe effects.
- A fixed timestamp/seed reproduces data and geometry.
- Browser console has no unexplained errors; dependencies are locked.
- Inspect desktop, portrait, initial frame, event climax, and paused/reduced frame.
- Report render performance on the actual test environment without implying a
  software-rendered desktop test proves physical-device performance.

Reject: ordinary admin tiles with a background gradient; disconnected random
numbers; six identical circles called agents; a giant empty centre; charts below
unreadable microtype; a screen recording offered as proof of real execution.
