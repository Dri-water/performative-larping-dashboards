# ABYSS — skill transfer fixture

This is a source snapshot from an independent-context finance exercise using the
packaged skill, without reading the repository's examples. Its first attempt was
visually insufficient. This version was produced by the same evaluator after the
skill gained the full-intensity recipe and optics helper.

```sh
npm ci
npm run dev
```

Open the Vite URL. `?t=11` holds the peak; `?hero=1&t=11` hides the HUD.
`npm run build` creates the static bundle. The fixture is deliberately standalone;
`optics.mjs` is the copied skill asset used during evaluation, not a live import.

This is evaluation evidence rather than a maintained application template. It has
a simple graphics fallback, procedural material limits, and no physical-phone
performance claim. All displayed market data is fictional. See the
[evaluation record](../../docs/evaluation/README.md) for the failure, repair,
rendered sequence, and verification scope.
