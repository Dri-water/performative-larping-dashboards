# VESPER — fresh skill transfer fixture

This is a source snapshot from a fresh-context weather/science exercise using the
revised packaged skill. The evaluator did not inspect the repository examples or
the earlier finance exercise. Its storm instrument was developed and critiqued
through actual desktop and portrait renders.

```sh
npm ci
npm run dev
```

Open the Vite URL. `?t=12` holds the peak; `?t=12&hero=1` hides the HUD.
`npm run build` creates a static bundle. The fixture is standalone; its copied
`optics.mjs` preserves the helper used during evaluation.

All telemetry is fictional. This is evaluation evidence rather than a maintained
application template. Surfaces remain procedural, portrait crops secondary
systems, and physical-phone performance is untested. See the
[evaluation record](../../docs/evaluation/README.md) for rendered evidence,
checks, hardware/software-renderer distinction, and limitations.
